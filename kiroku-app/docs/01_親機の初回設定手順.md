# 親機の初回設定手順(管理者向け)

目標: 管理者の実操作 5〜10分(実測は未実施。`tools\measure-install.ps1` で記録してください)

## 事前に用意するもの
- 親機にするパソコン(Windows 10/11 64bit、業務時間中ずっと起動できるもの)。**BitLocker(または「デバイスの暗号化」)を有効にしてください**(後述)
- 復旧キーを保管する紙/USBメモリ
- 子機4台と同じWi-Fi(**ルーターの「端末間通信の制限(AP分離)」は無効**)

## 手順
1. `KirokuApp-Setup-x.y.z.exe` を **管理者として** 実行(右クリック→管理者として実行)。
2. 「このパソコンを親機にする」を選び、「次へ」→「インストール」。
   → 共有サービスの登録、自動起動(Windows起動時)、ファイアウォール(同じネットワーク内のみ許可)、データ保存先の権限設定が**自動で**行われます。
3. インストール完了後、アプリが起動し「親機の初期設定」が出ます。管理者のお名前・ログインID・パスワード(10文字以上)を入力して「設定する」。
4. **復旧キー**が表示されます。「印刷する」または「ファイルに保存」で**パソコンの外**(紙・USBメモリ)に保管し、チェックを入れて「完了」。
5. ログイン画面が出るので、管理者でログインします。
6. 「管理」→「職員アカウント」で職員を登録(1人ずつ。共有アカウント禁止)。
7. 「管理」→「バックアップ」で **USBメモリ/外付けHDDを親機に挿し「別の媒体を設定」** (※次節の必須安全確認)。

## 必須安全確認(初期設定とは別に、導入日に必ず実施)
- [ ] 別媒体のバックアップが成功している(バックアップ画面の警告が消えている)
- [ ] 復旧キーを、親機とは別の場所に保管した
- [ ] 「バックアップを確認」で全件「正常」
- [ ] BitLocker有効(設定→プライバシーとセキュリティ→デバイスの暗号化、または `manage-bde -status`)。回復キーも別保管
- [ ] 親機の Windows ユーザー(管理者権限)を職員が共用していない
- [ ] 復元試験の予定日を決めた(`04_バックアップと復元手順.md`)

## 親機の運用
- 業務時間中は電源を入れ、スリープ・休止状態にしない(電源オプション→スリープなし)。
- Windows Update は止めないでください。更新で再起動しても共有サービスは自動で戻ります(実機での確認が必要)。

## 困ったとき
- 共有サービスが起動しない: 管理者のコマンドで `sc.exe query KirokuServer`。止まっていれば `sc.exe start KirokuServer`。
- 管理者パスワードを忘れた: 共有サービスを停止(`sc.exe stop KirokuServer`)し、管理者のコマンドで
  `"C:\Program Files\KirokuApp\server\Kiroku.Server.exe" reset-admin <ログインID>`(復旧キーが必要)。
