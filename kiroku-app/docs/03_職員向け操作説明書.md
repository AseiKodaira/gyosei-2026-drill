# 職員向け 操作説明書

## 毎日の流れ
**朝**: アプリを開く → ログイン → 左の一覧から利用者を選ぶ(いなければ「＋利用者を追加」) → 通所時間(「いま」ボタンで現在時刻) → 保存
**夕方**: 左の一覧から選ぶ → 退所時間・作業内容・利用者の様子 → 保存
**終礼**: 画面下の「終礼メモ」に入力 → 「終礼メモを保存」

## 画面の見かた
- 上: 日付(◀▶で前日・翌日、「今日」)、本日の利用人数、入力済み件数、保存の状態(「✓ 保存済み」が出たら保存できています)
- 左: 本日の利用者(通所・退所・入力の状況)
- 右: 入力欄 / 下: 終礼メモ

## 入力のコツ
- 氏名: 初めての方は名前をそのまま入力して保存 → 次回から一覧に出ます。文字を打つと候補が出ます。「▼一覧から選ぶ」でも選べます。
- 時間: 「9:30」「0930」どちらでも。「いま」ボタンで現在時刻。退所は空でも保存できます。
- 作業内容: 過去に入力した内容が候補ボタンで出ます。押したあとも自由に直せます。
- 利用者の様子: 昨日の内容は自動ではコピーされません。毎回その日の様子を書いてください。
- 保存: 「保存」ボタンか Ctrl+S。**「保存済み」と出るまでは保存されていません。**
- 「保存して次の利用者へ」で、続けて次の人を入力できます。
- Tabキーで 氏名 → 日付 → 通所 → 退所 → 作業 → 様子 → 保存 の順に移れます。

## 警告が出たとき
| 表示 | 意味と対応 |
|---|---|
| 赤い帯「親機に接続できません」 | 保存はできていません。入力は画面に残ります。Wi-Fiと親機を確認。つながったら「保存」。パソコンを閉じても、入力は一時退避され、次に開いたときに復元を聞かれます |
| 「他の職員が先に保存しています」 | 同じ記録を同時に直したため、相手の内容を消さないよう止めています。内容を見て、読み込む/上書き(相手の分は履歴に残る)を選びます |
| 「退所時間が通所時間より前です」 | 入力ミスの確認です。意図どおりなら「はい」 |
| 「同じ氏名の方がいます」 | 同じ方なら一覧から選んでください。別人(同姓同名)のときだけ別に登録 |

## 過去の記録
右上「過去の記録」→ 氏名・期間で検索 → 選ぶと内容表示。「この記録を修正する」で日々の記録画面に移ります。「修正履歴を見る」で修正前の内容がわかります。
印刷・PDF保存は、権限を許可された職員だけです(PDFは「Microsoft Print to PDF」を使います)。

## 守ってほしいこと
- 自分のIDとパスワードだけを使う。席を離れるときはログアウト。
- 印刷物は施錠できる場所に保管し、不要になったら裁断。
- 困ったら画面の日本語の案内に従い、解決しなければ管理者へ。

## knowbeへの転記用コピー(knowbe復旧後)
日々の記録画面の各項目名の横にある「📋 コピー」を押すと、**その項目の内容だけ**がコピーされます(項目名は付きません)。
対象: 氏名 / 日付(2026/10/05 の形) / 通所時間 / 退所時間(09:30 の形) / 作業内容 / 利用者の様子 / 終礼メモ。
1. 転記したい利用者と日付を選ぶ(保存済みの記録が表示されます)
2. 項目の「📋 コピー」を押す → 画面上部に「✓ コピーしました」(約2秒)
3. knowbeの該当欄をクリックして Ctrl+V で貼り付ける(貼り付けはご自身で行います。アプリは自動では送りません)
- 空欄の項目、未保存の変更がある間は、ボタンが押せません(古い内容のコピー防止)。先に保存してください。
- 日付・時刻がknowbeに貼り付けられない場合は、画面の表示を見て手入力してください(貼り付け可否は未確認です)。
- コピーしても記録は変わりません。コピーした内容は60秒後に自動で消去されます(その間に別の物をコピーしていれば消しません)。
- コピーした内容は他のアプリからも読める可能性があります。貼り付けたら、他の人に見える場所に貼らないでください。
