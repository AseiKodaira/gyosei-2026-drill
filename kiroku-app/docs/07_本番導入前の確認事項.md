# 本番導入前の確認事項

## 必須(未完了なら導入しない)
- [ ] `tools\build-windows.ps1` が成功し、インストーラーができた(ビルドエラーの修正を含む)
- [ ] `05_試験結果.md` の「Windows実機で必要な検証」8項目が完了し、結果を記録した
- [ ] 実際の5台で1日分の運用リハーサル(朝→夕方→終礼)を実施
- [ ] 別媒体バックアップ+**別PCでの復元試験**に成功、復旧キーを親機の外に保管
- [ ] BitLockerが親機で有効、親機のWindowsアカウントが共用されていない
- [ ] ルーターのAP分離が無効、Wi-Fiが暗号化(WPA2/WPA3)されている
- [ ] 職員全員が個人アカウントで1回ログインし、パスワードを変更済み
- [ ] 退職・異動時のアカウント無効化の担当者を決めた
- [ ] 印刷・PDF出力を許可する職員を決めた

## 事業所として確認が必要なこと(専門家にご確認ください)
- 本アプリは「日々の記録」と「終礼メモ」のみです。サービス提供記録などの**法定書類の全体を代替するものではありません**。他の書類は別途管理してください。
- 個人情報の取扱い方針、記録の保存期間・廃棄、横浜市への届出や指導監査で求められる記録形式との適合性は、所管(横浜市の担当部署)や社内規程でご確認ください。この文書は法的助言ではありません。
- 保存データの保持期間と、退所した利用者の記録の扱い(本アプリには削除機能がありません)。
