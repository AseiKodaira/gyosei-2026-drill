# 子機4台の接続手順

1台あたり約2〜3分(実測未実施)。

## 子機側
1. インストーラーを管理者として実行 →「このパソコンを子機にする」→ インストール。
2. アプリが起動し「親機につなぐ」が出ます。同じWi-Fiの親機が自動で見つかります。
3. **親機側**の管理者が「管理」→「接続端末」→「接続コードを表示」(8桁・10分有効・1回限り)。
4. 子機で親機を選び、接続コードを入力して「登録を申請する」。
5. **親機側**の「接続端末」に「★承認待ち」が出るので、見覚えのある端末名を確認して「承認する」。
6. 子機に自動でログイン画面が出ます。職員が各自のID・初期パスワードでログインし、新しいパスワードに変更します。

## 見つからないとき
画面に原因の目安が出ます。
- 「端末間通信の制限」の可能性: Wi-Fiルーターの設定で「AP分離」「プライバシーセパレーター」「ゲストネットワーク」を無効に。
- 親機のアドレス(管理画面の接続コード表示に出ます)を「親機のアドレス」欄に入力し「つながるか調べる」。
- 親機の電源・Wi-Fi接続・共有サービスの稼働を確認。

## セキュリティ
接続コードは「その親機本人にだけ通じる合言葉」でもあります。偽物の親機にはコードの証明ができないため、子機側で接続が中止されます。
