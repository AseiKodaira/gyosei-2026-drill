# 事業所記録アプリ(就労継続支援B型・完全オフライン / Windows 5台共有)

職員が毎日使う「日々の記録」と「終礼メモ」だけを、事業所内のWindows 5台で安全に共有するアプリです。
インターネット・クラウド・Webサイトは使いません(親機の共有サービスは事業所内LANだけに公開)。

## 現在の完成度(2026-10-22 時点・正直な一覧)

| 部分 | 状態 |
|---|---|
| 親機の共有サービス(暗号化DB・TLS・端末承認・職員認証・権限・監査ログ・同時編集制御・バックアップ/復元) | **実装済み。Linux上で自動試験57件合格**(下記) |
| 通信ライブラリ(証明書ピン留め・接続コードによる親機確認・LAN内自動検出・未保存入力の暗号化退避) | **実装済み・自動試験済み** |
| Windowsデスクトップ画面(WPF: 日々の記録/終礼メモ/過去の記録/管理者画面/印刷) | **ソースは書き終え、WPF参照アセンブリに対する型検査は合格。ただし一度も実行していない**(この環境はLinuxのため) |
| Windowsインストーラー(Inno Setup) | スクリプトは作成。**ビルドしていない**(Windowsが必要)。Windows用の親機サーバー(win-x64, 自己完結)のpublishだけはLinux上で成功 |
| knowbe転記用の項目別コピー(7項目) | ロジックは自動試験済み。ボタン/クリップボード動作はWindows実機で未検証 |
| Windows実機での動作(サービス登録・ファイアウォール・DPAPI・再起動復帰・5台構成) | **未検証** |
| Windows Hello ログイン、BitLocker検出、画面の無操作ロック | **未実装**(設計メモのみ) |

→ **まだ「完成品」ではありません。** Windows実機での検証(`docs/05_試験結果.md` の「未実施」欄)が終わるまで本番導入しないでください。

## フォルダ構成

```
src/Kiroku.Core     暗号化DB(SQLCipher)・業務ロジック・バックアップ・暗号
src/Kiroku.Server   親機の共有サービス(Kestrel+TLS / Windowsサービス / UDP自動検出 / CLI)
src/Kiroku.Client   子機・親機共通の通信部(証明書ピン留め・ペアリング・下書き退避)
src/Kiroku.App      Windows画面(WPF・XAMLなし/コードのみ) ※Windowsでビルド
tests/              自動試験(実際にTLSのサーバーを起動して検証)
installer/          Inno Setup スクリプト
tools/              build-windows.ps1(ビルド~インストーラー作成) / measure-install.ps1(所要時間記録) / AppTypeCheck(Linuxでの型検査用)
docs/               設計・手順書・試験結果・未解決事項
```

## ビルドと試験

Linux/Windows共通(画面以外): `dotnet test tests/Kiroku.Tests`
Windowsでインストーラー作成: PowerShellで `tools\build-windows.ps1`(.NET 8 SDK と Inno Setup 6 が必要。どちらも無償)
